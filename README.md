### 🔒 CARA KERJA - INI BUKAN VPN ASLI
AllOne pakai fitur "VPN" bawaan Android hanya sebagai SAKLAR LOKAL. 
BUKAN VPN untuk ganti IP/lokasi dan TIDAK terhubung ke server luar sama sekali.
Jadi 100% offline, tidak butuh internet, dan tidak kirim data kemanapun. Aman.

### 📲 CARA PAKAI
1. Install APK
2. Buka aplikasi, klik Coba Gratis 7 Hari
3. Centang aplikasi yang mau diblokir internetnya
4. Tekan Aktifkan Firewall, lalu izinkan VPN saat Android minta izin

### 🔑 LISENSI
Gratis coba 7 hari. Setelah habis, salin Device ID di dalam aplikasi dan hubungi admin untuk kode aktivasi permanen.

### ⚠️ PENTING
Saat pertama aktifkan, Android akan minta izin VPN. Itu NORMAL, karena sistem Android butuh izin itu untuk memutus internet. Jika ditolak, firewall tidak akan jalan.

### 🛡️ KEAMANAN & PRIVASI
Semua kerja di dalam HP saja, tidak lewat server luar, tidak kumpulkan data.
